# Project D — Submission Checklist

This checklist records the minimum items needed before the project is ready to submit.

## Phase 0 — Setup
- [x] Repository cloned and structure created
- [x] Python environment created
- [x] Requirements installed from `requirements.txt`
- [x] Research question written in the project README

## Phase 1 — Data collection
- [x] OpenAlex access tested
- [x] Search filter decided and documented
- [x] Candidate count recorded
- [x] Raw pull saved to `data/raw/`
- [x] External Scopus/SCImago files downloaded and stored under `data/external/`

## Phase 2 — Data dictionary
- [x] Core fields documented in `docs/data_dictionary.md`
- [x] ISSN normalization noted and explained
- [x] Known limitations recorded

## Phase 3 — Prepared datasets
- [x] Candidate papers created for ALL layer
- [x] Provisional STRICT layer created from Scopus matches
- [x] Country/institution tables created
- [x] Data quality / limitations documented

## Phase 4–6 — Analysis
- [x] RQ1 and RQ2 descriptive analysis completed
- [x] RQ3 collaboration analysis completed
- [x] RQ3 clustering/interpretation completed
- [x] Search validation / limitations completed

## Final checks before submission
- [ ] README links work and point to existing files
- [ ] All configuration values are set for the current environment
- [ ] Core scripts compile without syntax errors
- [ ] Outputs are saved in the expected processed folders
- [ ] Limitations and scope decisions are clearly documented
- [ ] Final narrative is consistent with the prepared data
